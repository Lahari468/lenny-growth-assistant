# Agent Development Transcripts

This directory records the use of coding agents during development.

The purpose is not to present AI-generated code as automatically correct. The transcripts document:

- the task given to the coding agent;
- relevant repository context;
- implementation generated;
- tests run;
- failures encountered;
- corrections requested;
- verification performed.

Secrets, credentials, personal data, and sensitive local configuration must be removed before committing transcripts.

## Planned Records

- `day-1-rag.md` — database, ingestion, embeddings, retrieval foundation
- `day-2-providers.md` — provider abstraction and Ollama provider
- `day-2-grounded-answer.md` — grounded answer service
- `day-2-agent-session-api.md` — required agent integration and session/chat API
- later records for Ship 30, artifacts, frontend, and deployment

## Documentation Principle

A coding-agent transcript is evidence of the development process, not a substitute for verification.

Each record should end with the actual test/verification result.
